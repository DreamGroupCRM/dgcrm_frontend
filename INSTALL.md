# Installation Commands

## Prerequisites
- Node.js 18+ (https://nodejs.org)
- npm 9+ or yarn

## Step 1: Install Dependencies
```bash
cd dream-group-crm
npm install
```

## Step 2: Start Dev Server
```bash
npm run dev
```
Visit: http://localhost:5173

## Step 3: Build for Production
```bash
npm run build
npm run preview
```

## Manual package install (if needed):
```bash
npm install react react-dom react-router-dom @reduxjs/toolkit react-redux axios @mui/material @emotion/react @emotion/styled @mui/icons-material sweetalert2 react-icons

npm install -D typescript vite @vitejs/plugin-react @types/react @types/react-dom tailwindcss postcss autoprefixer
```
